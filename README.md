# Trail Blazer -- create your own hike!
# Description: A walking path map that allows the user to choose a certain distance and creates a map around the perimeter of the user's current location
# Techstack: Javascript, HTML, CSS

# Usage: The user will choose a distance (in kilometers) that they want to travel (intended to be for walking, getting in steps), and the app will generate a walking path around that user's perimeter. The walking path is created by using Leaflet's API to create randomized routes around the surrounding streets.

# Additionally, the distance is calculated using the Earth's natural curve, since it will never be a completely straight line due to the Earth's circumference.
